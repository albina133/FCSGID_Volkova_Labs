# Лабораторная работа №2

В рамках лабораторной работы на основе предоставленного проекта было разработано приложение на **Python / PyQt5** с использованием механизма сигналов и слотов Qt.

В главном окне размещены три поля ввода для преобразования температуры между шкалами Цельсия, Фаренгейта и Кельвина. При изменении значения в любом из полей остальные автоматически пересчитываются.

Для интерфейса также было добавлено собственное оформление и дополнительный функционал:

- тёмный фон главного окна с фиолетовыми акцентами;
- разделение интерфейса на две области;
- интерактивный градусник со шкалой температур;
- изменение уровня и цвета жидкости в зависимости от температуры;
- плавная анимация изменения уровня жидкости;
- ограничение вводимых значений в диапазоне от −50 °C до +100 °C;
- кнопка возврата к исходным значениям.

Основная логика программы реализована через обработку сигналов `valueChanged` и использование пользовательских сигналов `mySignal`. Для предотвращения повторного вызова сигналов при автоматическом обновлении полей применяется метод `blockSignals()`.

Графический градусник реализован с помощью `QPainter`, а плавное изменение уровня жидкости − с использованием `QPropertyAnimation`.
