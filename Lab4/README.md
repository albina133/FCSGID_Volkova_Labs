# Лабораторная работа №4

В рамках лабораторной работы на основе предоставленного проекта **Painter** было доработано графическое приложение на **Python / PyQt5** с использованием **QML**. Основной задачей являлась реализация автоматического сохранения области рисования `Canvas` в файл по таймеру.

В приложении используется разделение на backend и frontend: программная логика реализована на Python, а графический интерфейс описан с помощью QML.

Исходный функционал приложения включает:

- рисование произвольных линий мышью на области `Canvas`;
- выбор одного из четырёх цветов кисти;
- настройку толщины линии с помощью пяти доступных значений;
- отображение инструментов и области рисования в главном окне Painter.

### Реализованная функциональность

Для выполнения задания был дополнен класс `Interface` в файле `main.py`. Автоматическое сохранение рисунка организовано следующим образом:

- с помощью `QTimer` запускается таймер с интервалом **5000 мс (5 секунд)**;
- при срабатывании таймера вызывается метод `save_canvas()`;
- пользовательский сигнал `saveRequested` передаёт из Python в QML путь к файлу;
- объект `Connections` в `mainWindow.qml` принимает сигнал и вызывает метод `canvas.save()`;
- содержимое области рисования автоматически сохраняется в файл `canvas_autosave.png`;
- при следующем срабатывании таймера изображение обновляется без создания дополнительных копий;
- результат сохранения отображается сообщением в консоли.

Взаимодействие между Python и QML реализовано с помощью `QQmlApplicationEngine` и `setContextProperty()`, благодаря которому объект `_backend` становится доступен графическому интерфейсу.

Для передачи команды сохранения используется механизм сигналов и слотов Qt. При этом исходная функциональность Painter была сохранена без изменений, а автоматическая запись изображения выполняется без дополнительных действий пользователя.
