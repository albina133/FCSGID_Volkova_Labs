
# Лабораторная работа №3

В рамках лабораторной работы было разработано графическое приложение на **Python / PyQt6** для взаимодействия с базой данных **SQLite** и выполнения SQL-запросов с отображением полученных результатов.

Графический интерфейс создан в среде **Qt Creator** с использованием Qt Designer. В главном окне размещены меню управления подключением, три функциональные кнопки, выпадающий список `QComboBox` и пять вкладок `QTabWidget`, содержащих таблицы `QTableView`.

Для демонстрации работы приложения была создана база данных `lab3.db`, включающая две таблицы:

- `students` — сведения о студентах, их идентификаторах и учебных группах;
- `grades` — сведения о дисциплинах и оценках студентов.

База данных содержит **10 студентов и 17 записей с оценками**.

### Основной функционал

- **Set connection** — выбор файла SQLite через `QFileDialog` и установка соединения с базой данных.
- **Tab1** — автоматическое отображение структуры базы данных после подключения с помощью запроса `SELECT * FROM sqlite_master`.
- **Tab2** — вывод названий объектов базы данных при нажатии кнопки `bt1` с использованием запроса `SELECT name FROM sqlite_master`.
- **Tab3** — выбор столбца системной таблицы `sqlite_master` через `QComboBox` и отображение соответствующих данных.
- **Tab4** — вывод сведений о студентах из таблицы `students` при нажатии кнопки `bt2`.
- **Tab5** — вывод сведений об оценках из таблицы `grades` при нажатии кнопки `bt3`.
- **Close connection** — закрытие соединения с базой данных, очистка результатов запросов и возврат интерфейса в исходное состояние.

Основная логика программы реализована в файле `mainwindow.py`, а графический интерфейс описан в `form.ui`. Для взаимодействия с SQLite используется встроенный модуль `sqlite3`.

Выполнение SQL-запросов организовано через метод `run_query()`, который получает данные из базы и отображает их в соответствующей вкладке. Для представления результатов используются `QStandardItemModel` и `QStandardItem`. Взаимодействие элементов интерфейса с программной логикой осуществляется через механизм сигналов и слотов Qt.

Дополнительно реализовано **модальное окно для ввода пользовательских SQL-запросов** с помощью `QInputDialog`. Оно позволяет самостоятельно выполнять `SELECT`-запросы, в том числе с использованием условий `WHERE`, и просматривать результаты в `Tab5`.

В приложении также предусмотрены обработка ошибок SQL через `QMessageBox`, блокировка функциональных элементов до подключения базы данных и отображение информации о выполненных запросах в строке состояния.
