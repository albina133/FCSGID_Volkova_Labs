# Лабораторная работа №1

В рамках лабораторной работы было создано приложение на **Qt Widgets / C++**.

В главном окне размещены текстовая надпись и кнопка.  
Изначально в центре окна отображается надпись **BOOM**. При нажатии на кнопку **SHOW AN IMAGE** текст заменяется изображением кота, загруженным через систему ресурсов Qt.

Для интерфейса также было добавлено собственное оформление:
- тёмный фон главного окна;
- оранжевый цвет надписи **BOOM**;
- кнопка оформлена в том же цвете;
- текст на кнопке сделан тёмным;
- элементы интерфейса выровнены по центру окна;
- изображение растягивается внутри области `QLabel`.

Для хранения изображения используется файл ресурсов `resources.qrc`, поэтому картинка является частью проекта и корректно загружается при запуске приложения.

Основная логика программы реализована через обработку нажатия кнопки: после события `clicked` в `QLabel` устанавливается изображение вместо текста.
